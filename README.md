# 基于多因子机器学习的股票收益预测与投资组合回测

**Machine Learning-Based Cross-Sectional Return Prediction and Portfolio Backtesting**

## 1. 项目概述

本项目研究能否利用简单的价格和成交量因子预测股票未来的横截面相对收益，并将预测结果用于构建只做多投资组合。

项目将比较传统线性模型与树模型，重点考察它们在严格样本外测试中的表现。研究特别关注：

- 时间顺序切分；
- 未来数据泄漏；
- 交易成本；
- 投资组合换手率；
- 模型过拟合；
- 回测结果的稳健性。

本项目的目标是完成一个方法正确、过程清晰、能够复现的研究型回测项目，而不是开发可直接用于实盘交易的系统。

## 2. Research Abstract

This project studies whether simple price- and volume-based factors can predict cross-sectional stock returns.

A linear model and a tree-based machine learning model will be compared using strictly time-ordered out-of-sample tests. The predictions will be converted into long-only portfolios and evaluated after transaction costs.

The main purpose is to build a transparent and reproducible research workflow, with particular attention to look-ahead bias, overfitting, turnover and robustness. This project is for educational and research purposes only.

## 3. 研究问题

本项目主要回答以下问题：

1. 简单的价格和成交量因子是否具有横截面收益预测能力？
2. 树模型的样本外表现是否优于传统线性模型？
3. 模型预测能力能否转化为扣除交易成本后的投资组合收益？
4. 结果在不同时间区间和参数设置下是否保持稳定？
5. 交易成本和换手率会在多大程度上削弱策略表现？

## 4. 暂定研究范围

- 股票数量：50—300只流动性较好的股票；
- 数据频率：日频；
- 输入数据：复权价格、成交量和交易日期；
- 预测目标：未来5日或20日相对收益；
- 投资方向：只做多；
- 调仓频率：与预测周期保持一致或通过实验确定；
- 研究用途：课程学习、作品集展示和方法研究。

暂不涉及：

- 高频交易；
- 强化学习；
- 实盘下单；
- 杠杆和复杂衍生品；
- 分钟级或逐笔数据；
- 复杂深度学习模型。

## 5. 暂定因子

项目计划使用3—5个容易解释的基础因子：

| 因子 | 暂定定义 | 可能反映的信息 |
|---|---|---|
| 20日动量 | 当前价格相对20个交易日前的收益 | 中期价格趋势 |
| 5日短期反转 | 过去5日收益的相反数 | 短期价格反转 |
| 20日波动率 | 过去20日日收益率的标准差 | 股票风险和价格不稳定程度 |
| 成交量变化 | 短期平均成交量相对长期平均成交量的变化 | 交易活跃度变化 |
| 均线偏离 | 当前价格相对移动平均线的距离 | 价格偏离近期趋势的程度 |

正式计算时，所有因子只能使用预测时点及以前可以获得的信息。

## 6. 预测目标

模型将预测股票未来5日或20日收益。为研究横截面选股能力，可以进一步将个股未来收益减去同期股票池平均收益：

```text
未来相对收益
= 个股未来收益 - 同期股票池平均收益
```

未来收益只能作为模型标签使用，不能进入当期因子。

## 7. 模型

### 基准模型

- 等权持有；
- Ridge回归；
- 简单因子排序组合。

### 机器学习模型

从以下模型中选择一种：

- Random Forest；
- XGBoost；
- LightGBM。

初始版本优先选择结构简单、容易解释和调试的模型，不追求模型数量。

## 8. 数据划分

数据必须按照时间顺序划分，例如：

```text
训练集 → 验证集 → 测试集
```

不会对全部样本进行随机打乱。测试集只能用于最终样本外评价，不能用于选择因子、调整参数或挑选表现最好的模型。

后续可以进一步采用滚动训练或扩展窗口测试：

```text
历史训练数据 → 预测下一阶段 → 更新时间窗口 → 再次预测
```

## 9. 模型评价指标

### 预测能力

- Rank IC；
- Pearson相关性；
- IC均值和稳定性；
- 不同预测分组的未来平均收益；
- 最高预测组与最低预测组之间的收益差。

### 投资组合表现

- 累计收益；
- 年化收益；
- 年化波动率；
- 夏普比率；
- 最大回撤；
- 换手率；
- 扣除交易成本后的收益。

## 10. 投资组合构建

初始回测采用只做多组合：

1. 在每个调仓日获得股票的样本外预测值；
2. 按预测值对股票排序；
3. 选择预测值最高的一组股票；
4. 使用等权或按预测排名分配权重；
5. 持有至下一个调仓日；
6. 根据权重变化计算换手率和交易成本。

回测将与以下基准进行比较：

- 市场指数；
- 股票池等权持有；
- 简单因子组合；
- Ridge模型组合；
- 树模型组合。

## 11. 交易成本

初始版本将同时考虑手续费和滑点：

```text
单次交易成本
= 交易金额 ×（手续费率 + 滑点率）
```

组合层面的成本将根据相邻调仓日的权重变化计算。具体参数会在实验中明确记录，并进行敏感性分析。

## 12. 防止数据泄漏

本项目遵守以下原则：

- 因子只能使用当时已经公开的数据；
- 未来收益只作为预测标签；
- 滚动统计先按股票和日期正确排序；
- 必要时将因子向后移动一个交易日；
- 数据标准化只能在训练集上拟合；
- 验证集和测试集不能参与模型训练；
- 模型预测必须早于组合持仓收益的发生时间；
- 不根据测试集表现反复调整参数；
- 对关键数据处理函数编写自动测试。


## 14. 运行环境

建议使用Python 3.11或兼容版本。

安装依赖：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

在Windows PowerShell中激活环境：

```powershell
.venv\Scripts\Activate.ps1
```

运行环境检查：

```bash
python scripts/check_environment.py
```

运行自动测试：

```bash
python -m pytest
```
